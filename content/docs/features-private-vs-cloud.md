# Private vs Cloud

NELA is **local-first**. You choose the path from the desktop top bar.

## Private

- Chat and library / File Indexer answers run on this device.
- Best after you have installed local models.
- Internet may still be used to **download models** or if you turn on **web search**.

## Cloud

- Sign in from Profile / Cloud settings.
- Answers use NELA Cloud **Fast**, **Smart**, and **Deep**.
- Smart and Deep usually need a plan or credits; Fast may include a free rolling window (see Pricing).
- Prompts leave this device. Files **attached to a Cloud chat** leave this device for that turn (the app warns you).

## Auto

Prefer Cloud when you are signed in and allowed to use it; otherwise use your local Smart model, with a clear notice.

## When does data leave the device?

| Action | Leaves device? |
|--------|----------------|
| Private chat / library / File Indexer | No (for inference) |
| Download a model | Download only |
| Web search on | Yes (fetch pages) |
| Cloud chat / Cloud attachments | Yes (to NELA Cloud) |
