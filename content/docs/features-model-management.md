# Model management

Install and tune **local** models from **Settings** when you use Private mode.

## What you can do

- Browse and download models by job (chat, vision, speech, retrieval helpers).
- See compatibility hints before a large download.
- Map Fast / Smart / Deep to the models you prefer.
- Adjust generation settings (length, creativity, and related knobs) without restarting.

Cloud tiers do not require these downloads — see [Models & quality](/docs/models).
