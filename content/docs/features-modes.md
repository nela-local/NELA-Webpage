# Modes

NELA switches personality by **mode**. Pick the mode that matches the job; you do not need every mode on day one.

For MSME money questions from live books, start with [Tally connector](/docs/features/tally) in Chat — that is the flagship path, not a separate mode label.

## Chat

Everyday conversation, Q&A, writing help, document questions, **Tally money answers**, and **creating files** (decks, sheets, HTML, Word).  
Use **Search my documents** / **Search my files** when answers should come from your library or File Indexer.

## Vision

Ask about an image you drop into the conversation — screenshots, diagrams, photos.

## Audio

Speech in and speech out: dictate prompts and listen to replies with on-device speech models.

## Podcast

Turn material from your documents into a two-speaker podcast script and audio episode.

## Mindmap

Grow a visual concept tree from your docs or from a topic — useful for studying and planning.

## Switching

Use the mode controls in the main window. Each mode can use different models in Private settings; Cloud uses Fast / Smart / Deep tiers when Cloud is selected.
