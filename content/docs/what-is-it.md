# Welcome

NELA is the **private AI that sits next to Tally** and tells Indian MSME owners—in plain language—how their business is doing. It is a **local-first desktop** app: Private mode runs models on your computer. When you want more power, sign in for optional **NELA Cloud**.

## What you can do

- Connect **TallyPrime** (read-only) and ask: cash / bank, who owes me, what did we sell?
- On Cloud: open a **live HTML dashboard** or export **Excel** for your CA.
- Chat, write, and reason with Fast / Smart / Deep quality tiers.
- Ask about **folders** with the [File Indexer](/docs/features/file-indexer) (**Search my files**).
- Ask about curated uploads in the [Document library](/docs/features/local-indexing) (**Search my documents**).
- [Create files](/docs/features/artifacts) — presentations, Excel, HTML, Word — with live preview.
- Use [modes](/docs/features/modes) for vision, audio, podcasts, and mindmaps.
- Keep work in **workspaces** you can export as `.nela` projects.

## Flagship for business owners

Start with the [Tally connector](/docs/features/tally): enable HTTP Server in TallyPrime, connect in Settings → Connections, and ask money questions in plain language. NELA **never writes vouchers**.

## Private vs Cloud (in one minute)

| | Private | Cloud |
|---|---|---|
| Where answers run | On this device | NELA Cloud over the internet |
| Document library / File Indexer | Stay local | Still local unless you attach files to that chat |
| Tally Q&A | Text summaries available | Live dashboard + Excel export |
| Best for | Offline-capable work after models are installed | Hosted Fast / Smart / Deep without downloading huge models |

Full detail: [Private vs Cloud](/docs/features/private-vs-cloud).

## Suggested path

1. [Get started](/docs/installation) — install and open a workspace.
2. [Connect Tally](/docs/features/tally) — enable HTTP Server and ask your first money question.
3. Turn on the [File Indexer](/docs/features/file-indexer) for a real project folder.
4. Try [Create files](/docs/features/artifacts) when you need a deck or spreadsheet.

> [!TIP]
> You do not need Cloud to try Tally text answers. Dashboards and Excel export need Cloud.
