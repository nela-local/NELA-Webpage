# Private inference

In **Private** mode, answers are generated by models installed on your computer. You do not need NELA Cloud for everyday chat, library Q&A, or File Indexer search.

## What that means for you

- Prompts for Private turns stay on this device for generation.
- You pick Fast / Smart / Deep from models you installed.
- Optional Cloud is separate — see [Private vs Cloud](/docs/features/private-vs-cloud).

## When something fails

NELA can try another installed model that fits the task. If nothing is installed for that mode, open Settings and download one.
