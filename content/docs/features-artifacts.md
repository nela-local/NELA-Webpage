# Create files

Ask NELA in **Chat** to produce real files you can download and edit outside the app.

## What you can make

- **Presentations** — HTML slide decks you can preview in NELA, then save as **PowerPoint**, **PDF**, **Word**, or **HTML**.
- **Spreadsheets** — Excel workbooks for tables, trackers, and dashboards.
- **Web pages** — self-contained HTML (landing pages, one-pagers, simple tools).
- **Word documents** — flowing `.docx` write-ups from the same HTML-style artifacts.

Cloud often helps with richer decks and longer documents; Private mode still works with your installed models. See [Private vs Cloud](/docs/features/private-vs-cloud).

## How it usually goes

1. Say what you want (“Make a 8-slide pitch deck about …”).
2. Watch the live preview in the artifact panel.
3. Edit in place when the UI offers it (text, colors on slides, and so on).
4. Download in the format you need.

## Tips

- Be specific about audience, length, and must-have sections.
- Attach a brief or source file when the content must match a document you already have.
- For decks, prefer clear 16:9 slides — NELA’s export path is tuned for that layout.
